### Получение учебной конфигурации сервиса типа NodePort из развернутого конфигурации сервиса `CoreDNS`

#### Команда получения конфигурации сервиса CoreDNS

```bash
kubectl get svc -o yaml kube-dns -n kube-system
```

<details>
<summary>
Конфиг учебного сервиса типа NodePort
</summary>

**Команда: создание манифеста NodePort сервиса**

```bash
cat > my-nodeport.yaml <<'EOF'
apiVersion: v1
kind: Service
metadata:
  annotations:
    prometheus.io/port: "9153"
    prometheus.io/scrape: "true"
  labels:
    k8s-app: kube-dns
    kubernetes.io/cluster-service: "true"
    kubernetes.io/name: CoreDNS
  name: kube-dns-2
  namespace: kube-system
spec:
  ipFamilies:
  - IPv4
  ipFamilyPolicy: SingleStack
  ports:
  - name: dns
    port: 53
    protocol: UDP
    targetPort: 53
  - name: dns-tcp
    port: 53
    protocol: TCP
    targetPort: 53
  - name: metrics
    port: 9153
    protocol: TCP
    targetPort: 9153
  selector:
    k8s-app: kube-dns
  sessionAffinity: None
  type: NodePort
status:
  loadBalancer: {}
EOF
```

</details>

#### Применение манифеста при создании

```bash
kubectl create -f my-nodeport.yaml
```

<details>
<summary>
Вывод о создании учебного сервиса типа NodePort

**Лог: результат создания сервиса**
